# Finora — Expense Tracker

A full-stack personal finance app: expenses, income, budgets, recurring
bills, split expenses, multi-account balances, analytics, and an AI-powered
spending assistant (Google Gemini).

Express/MongoDB API + React/Vite frontend, deployed as a **single service**
— Express serves the built frontend directly, so there's one domain, no
CORS, and no cross-site cookie issues.

## Features

| Area | What it does |
|---|---|
| Auth | Register/login, session via an `httpOnly` JWT cookie |
| Expenses | Add/edit/delete, filter by category/payment method/date range, search, pagination |
| Income | Track income entries, recent-income table |
| Recurring expenses | Recurring bills with an upcoming-7-days view and category summary |
| Accounts | Multiple accounts with balances and net balance |
| Split expenses | Track shared expenses across participants, owed/paid status, split-evenly helper |
| Budget | Set a monthly budget, see live progress |
| Analytics | Spending by category (pie), daily spending (bar), highest/average expense |
| Ask AI | One-click AI spending analysis + a chat interface for financial questions (Gemini) |
| Dashboard | Balance, income/expenses/savings this month, spending trend, budget progress, recent transactions, upcoming bills |

## Stack

- **Backend**: Node.js, Express 5, MongoDB/Mongoose, JWT auth, node-cron
  (recurring expenses), LangChain + Google Gemini (AI features)
- **Frontend**: React 18, React Router 6, Vite, Tailwind CSS, Axios, Recharts,
  lucide-react

## Local development

Two ways to run it:

**Two dev servers (hot reload on both):**
```bash
npm run dev:backend    # Express on :3000
npm run dev:frontend   # Vite on :5173, proxies /api to :3000
```

**Production-like, one server:**
```bash
npm run build   # builds the frontend into Backend/public
npm start       # serves everything from :3000
```

Either way, first set up the backend's environment:
```bash
cd Backend
cp .env.example .env   # fill in MONGO_URI, JWT_SECRET, GOOGLE_API_KEY
```

No env file is needed on the frontend for local dev — API calls go to the
relative path `/api`, which Vite proxies to the backend automatically.
